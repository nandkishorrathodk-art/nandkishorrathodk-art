## Featured project

### SONIC —

SONIC is an ongoing project exploring how an AI system can work with a computer workstation. It brings together task reasoning, desktop interaction, execution tools, and verification.

- **Task orchestration:** Breaks larger objectives into bounded tasks and coordinates worker agents.
- **Verification:** Uses tests, execution receipts, and observed outcomes to evaluate results.
- **Persistence:** Develops durable identity, memory, and project artifacts.

**Current status:** An actively evolving engineering project. Capability and reliability depend on the task and runtime environment; tests alone do not establish success on every real-world workflow.

**Technologies:** `Python` · `FastAPI` · `TypeScript` · `Next.js` · `Docker` · `SQLite` · `Neo4j`
